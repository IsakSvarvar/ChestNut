# ChestNut
## A Computercraft based storage and logistics system

This system can run on its own but it's originally made with the Create and Advanced Peripherals mods in mind

Usage:
In a CC computer, run:
```
wget https://raw.githubusercontent.com/IsakSvarvar/ChestNut/main/install.lua
install
```

If you want to install from another branch (e.g dev), run:
```
wget https://raw.githubusercontent.com/IsakSvarvar/ChestNut/dev/install.lua
install dev
```
